# Amostras públicas de engenharia

Estes são **projetos públicos de demonstração**, não comprovações de implantação em produção ou impacto comercial. Os repositórios são a fonte principal das evidências.

## 1. Log Anomaly Detector

**Repositório:** [SkAdr1an/log-anomaly-detector](https://github.com/SkAdr1an/log-anomaly-detector)

**Problema explorado:** analisar registros de eventos e identificar comportamentos anômalos.

**Implementação documentada:**
- Python e scikit-learn para análises orientadas à detecção de anomalias.
- Exportação de relatórios CSV e gráficos PNG.
- Dados sintéticos para demonstração e experimentação.

**O que demonstra:** fluxos de processamento de dados, geração de saídas estruturadas e prototipação analítica.

**Limites:** a documentação pública não comprova precisão em produção, benchmarks ou implantação para clientes.

## 2. HelpDesk Laravel

**Repositório:** [SkAdr1an/helpdesk-laravel](https://github.com/SkAdr1an/helpdesk-laravel)

**Problema explorado:** gerenciar chamados com autenticação e isolamento de dados entre usuários.

**Implementação documentada:**
- Laravel 12, PHP 8.3, MVC, Blade, Tailwind e SQLite.
- Criação, listagem, visualização, edição e exclusão de tickets.
- Autenticação e autorização restrita ao usuário.
- Validações de formulário e rotas protegidas.

**O que demonstra:** aplicações CRUD, fundamentos de desenvolvimento web, autenticação e autorização.

**Limites:** o próprio repositório apresenta o projeto como exercício técnico. Não é divulgado como sistema comercial implantado.

## Como avalio o desenvolvimento de software

Priorizo definição do problema, escopo, controle de acesso, tratamento de dados, estratégia de testes e limitações operacionais. Projetos públicos demonstram código e aprendizado; trabalhos profissionais podem exigir autorização de divulgação e indicadores mensurados.
